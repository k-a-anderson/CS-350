# CS 350 Portfolio Reflection

## Project Summary

In this course, I developed several embedded systems applications using a Raspberry Pi and various hardware peripherals. The two artifacts I selected for my portfolio are the Morse Code State Machine project and the Smart Thermostat Final Project. These projects demonstrate my ability to design and implement software that interacts directly with hardware components through GPIO, I2C, UART, sensors, buttons, LEDs, and LCD displays.

The final thermostat project solved the problem of creating a prototype smart thermostat capable of monitoring temperature, displaying information to the user, controlling heating and cooling indicators, and simulating communication with a remote server. The Morse code project demonstrated how state machines can be used to manage timing, user input, and hardware outputs in an organized and maintainable manner.

## What I Did Particularly Well

One area where I performed well was troubleshooting hardware and software integration issues. Throughout the course, I learned how to identify wiring problems, GPIO configuration issues, and software bugs. I was able to successfully build and test working circuits while implementing the required functionality through Python code and state machine design.

I also became comfortable working with multiple communication interfaces, including GPIO, I2C, and UART. These projects required coordinating several hardware components simultaneously while maintaining reliable operation.

## Where I Could Improve

I could improve my initial planning and documentation process. In several projects, I spent additional time troubleshooting issues that may have been easier to identify if I had created more detailed diagrams and testing plans before implementation. I would also like to continue improving my understanding of embedded system architecture and communication protocols.

## Tools and Resources Added to My Support Network

Throughout this course, I became more familiar with Raspberry Pi documentation, Python libraries, GPIOZero, serial communication tools, and state machine design techniques. I also learned how to use GitHub for project storage and portfolio development. These resources will continue to be useful in future coursework and technical projects.

## Transferable Skills

The skills developed during this course are highly transferable to other technology projects. These include debugging hardware and software systems, implementing state machines, working with sensors and peripherals, reading technical documentation, and developing software that interacts with physical devices. I also strengthened my problem-solving and troubleshooting abilities when working with unfamiliar hardware configurations.

## Maintainability, Readability, and Adaptability

I made my projects maintainable and readable by using comments, descriptive variable names, organized state machine structures, and modular code. Separating functionality into methods and clearly documenting the purpose of each section made the code easier to understand and modify. The state machine approach also improved adaptability because additional functionality and states can be added without requiring major changes to the overall program structure.
